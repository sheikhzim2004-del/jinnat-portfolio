# 🚀 Personal Developer Portfolio - Jinnat Islam

A sleek, interactive, and high-performance developer portfolio built with **Next.js 16**, **Tailwind CSS**, and **Framer Motion**. Designed to showcase MERN stack web applications, front-end expertise, and interactive UI components with smooth scroll animations.

🔗 **Live Portfolio:** [jinnat-portfolio.vercel.app](https://jinnat-portfolio.vercel.app)

---

## ✨ Highlights & Features

- **⚡ Next.js 16 App Router:** Highly optimized rendering, clean project architecture, and fast load times.
- **🎨 Modern Dark Theme UI:** Custom dark-themed layout with glowing blue accents and fluid typography.
- **🎬 Reusable Framer Motion Animations:** Custom animation wrappers (`FadeIn`, `AnimatedHeading`) for smooth scroll and entry interactions.
- **📱 Responsive Layout:** Seamless user experience across mobile, tablet, and desktop screens.
- **💼 Dynamic Project Showcase:** Real-world full-stack and front-end projects with direct live previews and dual-repository (Client/Server) code links.

```text
